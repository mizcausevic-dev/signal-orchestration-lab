# Security Policy

## Scope

Signal Orchestration Lab is a portfolio project built to demonstrate
orchestration, routing, and escalation logic for enterprise operating signals.
It uses synthetic data only.

## Reporting

If you identify a security concern in this repository, please avoid posting
sensitive details publicly. Reach out through:

- [Kinetic Gain](https://kineticgain.com/)

## Safe Defaults

- no production secrets are committed
- synthetic signal payloads only
- environment values documented in `.env.example`
- CI validates core Python quality on push and pull request
